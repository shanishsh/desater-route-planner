**Classification Standards**:
- `VERIFIED_WORKING`: The full relevant path was actually exercised successfully with live runtime or automated test evidence.
- `CONNECTED_NOT_RUNTIME_VERIFIED`: Code connections exist through all layers, but runtime behavior has not been tested on an active device/emulator.
- `PARTIALLY_CONNECTED`: Some components work, but at least one critical step in the chain is broken or missing.
- `DISCONNECTED`: A screen, button, API, service, or model has no effective connection to its intended destination.
- `BROKEN`: A concrete defect (crash, syntax error, HTTP 404/500) prevents the feature from functioning.
- `NOT_CONFIGURED`: Required external credentials, API keys, or infrastructure is missing.
- `NOT_IMPLEMENTED`: The advertised capability does not exist in code.
- `BLOCKED`: Verification cannot proceed because of an external environmental limitation.
